# Primer Parcial Programación III

## Puntos realizados
- **Maquetado (HTML):** Etiquetas semánticas  con header, navegación, contenido principal y footer.

- **Estilos (CSS):** Usé Flexbox para acomodar los productos. Todo el diseño (colores, tamaños) está centralizado usando variables CSS para mantenerlo súper prolijo.
- **Lógica (JS):** Hice un sistema para agregar, restar y borrar artículos del carrito. Además, calcula el total del ticket en la página final.

## Cositas extras

- **Destructuring:** Usé lo de la última clase para dejar el código más fachero.

- **Código modular y organizado:** Me salí un poquitito de las funciones por defecto, para tratar de que tengan responsabilidad única. 

- **Alerts:** Metí los mensajes de alerta adentro de un objeto literal para manejarlos fácil.

- **Eventos limpios:** Para manejar los eventos usé la misma lógica DRY de Programación I, intentando que no haya dos funciones sumar y restar, sino una sola actualizar y por parámetro poder cambiar su accionar.

- **Detallito extra de UX:** Clavé un botoncito flotante jajaja y el nav en stick.
